# Участие в разработке Luma

Спасибо за интерес к улучшению Luma! Этот проект расширяет визуальные возможности терминала, и мы рады любому вкладу.

## 🐛 Сообщение об ошибках и предложения

Если вы столкнулись с ошибкой или у вас есть отличная идея (например, новый алгоритм рендеринга, дизеринг или поддержка анимаций), откройте **Issue** на GitHub. Пожалуйста, укажите:
- Вашу операционную систему и эмулятор терминала (например, Fedora с Alacritty, Ubuntu с Kitty, Windows Terminal).
- Точную команду и аргументы, вызвавшие проблему.
- По возможности, пример сгенерированного ASCII-арта или исходное изображение.

## 🛠️ Внесение изменений в код

1. Сделайте **Fork** репозитория на GitHub.
2. Создайте **новую ветку** для функционала или исправления (`git checkout -b feature/awesome-new-engine`).
3. Напишите код и протестируйте его. Основная логика находится в `lumart.py`.
4. Зафиксируйте изменения с понятным сообщением (`git commit -m 'feat: новый алгоритм XYZ'`).
5. Отправьте изменения в свой форк (`git push origin feature/awesome-new-engine`).
6. Создайте **Pull Request**.

### Архитектура проекта
- `lumart.py`: Полное ядро движка: перцептивное смешивание цветов в Linear RGB, дизеринг по матрице Байера, рендеринг шрифтом Брайля и полублоками, а также многоязычный CLI.
- `install.sh`: Универсальный Plug & Play установщик, совместимый с Fedora, Debian/Ubuntu, Arch Linux, openSUSE и macOS.
- `build_packages.sh`: Скрипт автоматической сборки бинарных файлов через `PyInstaller` и пакетов `.deb`, `.rpm`, `PKGBUILD`.
- `pyproject.toml`: Конфигурация сборки с поддержкой `pipx install .` и `pip install --user .`.

### Правила разработки
- **Без тяжелых зависимостей**: Luma должна оставаться легковесной и готовой к запуску без лишней настройки. Зависимости ограничены Pillow (`PIL`) и стандартной библиотекой Python.
- **Эстетика терминала**: Любой новый режим должен обеспечивать максимальное визуальное качество.
- **Многоязычность**: При добавлении новых флагов CLI или сообщений обновляйте словарь `TRANSLATIONS` для всех 7 языков (`en`, `es`, `pt`, `ru`, `ja`, `de`, `ko`).
