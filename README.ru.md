# Luma

**Высокоточный движок для рендеринга изображений в терминале, написанный на Python.**

Luma — это терминальный движок с открытым исходным кодом, созданный с одной целью:

> **Максимальная визуальная точность при минимальном пространстве терминала.**

В отличие от традиционных конвертеров ASCII, которые просто преобразуют яркость изображения в символы, Luma использует различные системы терминальных глифов, математику цветов Linear RGB и методы рендеринга, чтобы сохранить как можно больше визуальной информации в ограниченном количестве ячеек терминала.

## Особенности

* Высокоточный рендеринг изображений в терминале
* Рендеринг на основе ASCII, шрифта Брайля и Блоков
* **Рендеринг в стиле ОС (`--os-style`)**: Классические терминальные символы (точки, буквы) для логотипов в стиле Neofetch.
* **Замена цветов в реальном времени (`--swap`)**: Динамическая замена до 5 цветов на основе евклидова цветового расстояния в 3D.
* **Эпический цветовой движок (По умолчанию)**: Усредняет цвета в пространстве Linear RGB для предотвращения "грязных" цветов, одновременно применяя динамический контраст и насыщенность (HDR).
* Настраиваемая ширина вывода
* Поддержка Truecolor в терминале (24-битный ANSI)
* Разработано для экстремально маленьких размеров вывода
* Написано на Python и легко расширяется

## Пример

```bash
# Конвертация изображения с использованием шрифта Брайля, цветов и замены фиолетового на розовый
luma image.png -w 45 --braille -c --swap purple pink
```


## Установка

Вы можете запустить Luma напрямую из исходного кода или скомпилировать его в нативный пакет Linux (DEB, RPM или Arch PKGBUILD).

**Вариант 1: Загрузка готовых пакетов (Рекомендуется)**
Вы можете скачать готовые к использованию пакеты `.deb` или `.rpm` прямо со страницы [GitHub Releases](https://github.com/SilentBlox01/Luma/releases).

**Вариант 2: Запуск напрямую из исходного кода**
```bash
git clone https://github.com/SilentBlox01/Luma.git
cd Luma
# Убедитесь, что у вас установлен Pillow
pip install -r requirements.txt
python3 lumart.py --help
```

**Вариант 3: Самостоятельная компиляция и сборка нативных пакетов**
Luma включает в себя автоматизированный скрипт сборки для создания автономного бинарного файла с помощью PyInstaller.
```bash
chmod +x build_packages.sh
./build_packages.sh
```
После компиляции вы можете установить программу глобально с помощью вашего пакетного менеджера:
- **Debian/Ubuntu**: `sudo apt install ./dist/lumart-2.0.0.deb`
- **Fedora/RHEL**: `sudo dnf install ./dist/lumart-2.0.0.rpm`
- **Arch Linux**: `cd dist/arch && makepkg -si`

## Использование

Если вы установили пакет, вы можете запускать `lumart` или `luma` откуда угодно. В противном случае запустите скрипт python напрямую.

```bash
# Базовое использование
python3 lumart.py image.png
```

Укажите ширину вывода (в символах):
```bash
python3 lumart.py image.png -w 30
```

Включите высокоточный рендеринг Брайля с поддерлькой Truecolor:
```bash
python3 lumart.py image.png --braille -c
```

Принудительно включите рендеринг символов в ретро-стиле ОС (полезно для логотипов ОС):
```bash
python3 lumart.py image.png --os-style -c
```

## Удаление

Если вы хотите удалить Luma из вашей системы, команда зависит от того, как вы ее установили:

**Если установлено через пакетный менеджер (.deb, .rpm, PKGBUILD):**
- **Debian/Ubuntu**: `sudo apt remove lumart`
- **Fedora/RHEL**: `sudo dnf remove lumart`
- **Arch Linux**: `sudo pacman -Rns lumart`

**Если установлено через pip:**
```bash
pip uninstall lumart
```

**Если установлено вручную:**
Вы можете запустить предоставленный скрипт удаления:
```bash
chmod +x uninstall.sh
./uninstall.sh
```

## Философия

Терминальный рендеринг — это форма визуального сжатия.

Задача состоит не просто в преобразовании изображения в символы. Задача состоит в том, чтобы представить наибольшее количество визуальной информации, используя наименьшее количество ячеек терминала.

Поэтому Luma фокусируется на **перцептивной точности**, используя математически точные цветовые пространства (Linear RGB вместо sRGB) и динамические кривые HDR, а не просто создавая узнаваемый ASCII-арт.
