# Luma

**Высокоточный движок для рендеринга изображений в терминале, написанный на Python и современном C/C++.**

Luma — это терминальный движок с открытым исходным кодом, созданный с одной целью:

> **Максимальная визуальная точность при минимальном пространстве терминала.**

В отличие от традиционных конвертеров ASCII, которые просто преобразуют яркость изображения в символы, Luma использует различные системы терминальных глифов, математику цветов Linear RGB и нативные алгоритмы компьютерного зрения на C/C++, чтобы сохранить как можно больше визуальной информации в ограниченном количестве ячеек терминала.

## Особенности

* Высокоточный рендеринг изображений в терминале
* Рендеринг на основе ASCII, шрифта Брайля и Блоков
* **Гибридная двухдвижковая архитектура**:
  * **Цветовой движок Linear RGB** (Python / Pillow): Динамические кривые контраста HDR, смешивание в линейном цветовом пространстве ($C_{\text{linear}} = C_{\text{srgb}}^{2.2}$) и 24-битный TrueColor ANSI.
  * **Высокопроизводительный монохромный движок и манга** (Нативный C++17): Выполнение менее чем за 10 мс, выделение контуров методом разности гауссиан (DoG), диффузия ошибки Билла Аткинсона (1984, MacPaint) и растровые сетки Байера 8x8 (*Ami-tone*).
* **Селектор движка (`-E`, `--engine`)**: Динамическое переключение между `color`, `mono`, `bw`, `manga` и `sketch`.
* **Режим чистого эскиза (`-s`, `-E sketch`)**: Выделение четких контуров без растра и шума для аниме и иллюстраций.
* **Manga Screentone 2.0 (`-m`, `-E manga`)**: Аутентичный полутоновый растр манги для полутонов с чистым белым цветом бумаги и глубокими черными чернилами.
* **Дизеринг Аткинсона и полутона (`-d` / `--dither`)**: Поддержка `atkinson`, `floyd`, `bayer` и `none`.
* **2x2 квадрантные HD-блоки (`--blocks`)**: 4 субпикселя на ячейку с использованием квадрантных символов Unicode (`▘▝▀▖▌▞▛▗▚▐▜▄▙▟█`).
* **Рендеринг в стиле ОС (`--os-style`)**: Классические терминальные символы (точки, буквы) для логотипов в стиле Neofetch.
* **Замена цветов в реальном времени (`--swap`)**: Динамическая замена цветов на основе евклидова цветового расстояния в 3D.
* **Ноль внешних нативных зависимостей**: C++ движок полностью автономен и использует заголовки общественного достояния (`stb_image.h` и `stb_image_resize2.h`). OpenCV и libpng не требуются.
* **Полный паритет с резервным вариантом на Python**: При отсутствии компилятора C++ Luma плавно переключается на чистый Python без сбоев.
* Настраиваемая ширина вывода и автоопределение светлого/темного терминала (`-i`, `--invert`)
* Интерактивный набор инструментов для обновления (`-uu`), отката (`-dg`) и проверки (`-u`)
* Полная диагностика системы и движков (`-v`, `--version`)

## Пример

```bash
# Конвертация изображения с использованием шрифта Брайля, цветов и замены фиолетового на розовый
luma image.png -w 45 --braille -c --swap purple pink
```

## Установка

Вы можете установить Luma одной командой, запустить напрямую из исходного кода или скомпилировать в нативный пакет Linux (DEB, RPM или Arch PKGBUILD).

**Быстрая установка (Рекомендуется):**
```bash
curl -fsSL https://raw.githubusercontent.com/SilentBlox01/Luma/main/install.sh | bash
```

**Вариант 1: Запуск напрямую из исходного кода / Локальный установщик**
```bash
git clone https://github.com/SilentBlox01/Luma.git
cd Luma
./install.sh
```

**Вариант 2: Загрузка готовых пакетов**
Вы можете скачать готовые к использованию пакеты `.deb` или `.rpm` прямо со страницы [GitHub Releases](https://github.com/SilentBlox01/Luma/releases).

**Вариант 3: Самостоятельная компиляция и сборка нативных пакетов**
Luma включает в себя автоматизированный скрипт сборки для создания автономного бинарного файла с помощью PyInstaller:
```bash
chmod +x build_packages.sh
./build_packages.sh
```
После компиляции вы можете установить программу глобально с помощью вашего пакетного менеджера:
- **Debian/Ubuntu**: `sudo apt install ./dist/lumart-*.deb`
- **Fedora/RHEL**: `sudo dnf install ./dist/lumart-*.rpm`
- **Arch Linux**: `cd dist/arch && makepkg -si`

**Вариант 4: Ручная компиляция нативного C++ движка**
Если вы хотите скомпилировать только нативный движок C++ без сборки полных пакетов:
```bash
# Автономный CLI бинарник:
g++ -O3 -std=c++17 monochrome.cpp -o luma-mono

# Разделяемая библиотека (для внутрипроцессного ускорения через ctypes из Python):
g++ -O3 -std=c++17 -fPIC -shared monochrome.cpp -o libmonochrome.so
```

## Использование

Если вы установили пакет или использовали установщик, вы можете запускать `lumart` или `luma` из любого каталога. В противном случае запускайте python-скрипт напрямую.

> **💡 Совет:** Luma отлично работает с прозрачными фонами! Движок автоматически игнорирует прозрачные пиксели, благодаря чему логотипы и персонажи идеально выделяются на фоне вашего терминала.

```bash
# Базовое использование
python3 lumart.py image.png
```

Указание ширины вывода (в символах):
```bash
python3 lumart.py image.png -w 30
```

Включение рендеринга шрифтом Брайля с поддержкой Truecolor:
```bash
python3 lumart.py image.png --braille -c
```

Режим чистого эскиза (четкие контуры DoG без шума):
```bash
python3 lumart.py image.png -E sketch -w 100
# или: python3 lumart.py image.png -s -w 100
```

Режим Manga Screentone 2.0 (контуры DoG + растр Байера 8x8):
```bash
python3 lumart.py image.png -E manga -w 120
# или: python3 lumart.py image.png -m -w 120
```

Монохром с дизерингом Аткинсона (1984 MacPaint):
```bash
python3 lumart.py image.png -E mono -d atkinson -w 100
# или классический Флойд-Стейнберг: python3 lumart.py image.png -E mono -d floyd -w 100
```

2x2 квадрантные HD-блоки:
```bash
python3 lumart.py image.png -E mono --blocks -w 80
```

Чистый монохром без цветов:
```bash
python3 lumart.py image.png -E mono --braille -w 100
```

Классический рендеринг в стиле ОС:
```bash
python3 lumart.py image.png --os-style -c
```

Отображение полной диагностики системы и движков:
```bash
luma -v
# или: luma --version
```

## Обновление и откат

Luma предоставляет явный контроль над обновлениями и откатом:

- **Проверка наличия обновлений (без загрузки и изменений):**
  ```bash
  luma -u
  # или: luma --update / luma --check-update
  ```
- **Интерактивное обновление:**
  ```bash
  luma -uu
  # или: luma --upgrade
  ```
  *(Позволяет выбрать версию с предварительным просмотром описания релиза и автобэкапом в `~/.config/luma/backup/`)*

- **Интерактивный откат / Даунгрейд:**
  ```bash
  luma -dg
  # или: luma --downgrade / luma --rollback
  ```
  *(Открывает меню для выбора между локальными резервными копиями или релизами GitHub)*

  Вы также можете указать версию напрямую:
  ```bash
  luma -dg 2.1.0
  ```

## Удаление

Если вы хотите удалить Luma из вашей системы:

**При установке через пакетный менеджер (.deb, .rpm, PKGBUILD):**
- **Debian/Ubuntu**: `sudo apt remove lumart`
- **Fedora/RHEL**: `sudo dnf remove lumart`
- **Arch Linux**: `sudo pacman -Rns lumart`

**При установке через pip:**
```bash
pip uninstall lumart
```

**При ручной установке:**
```bash
chmod +x uninstall.sh
./uninstall.sh
```

## Философия

Рендеринг в терминале — это форма визуального сжатия.

Задача состоит не просто в том, чтобы преобразовать изображение в символы. Задача состоит в том, чтобы передать как можно больший объем визуальной информации с использованием наименьшего количества ячеек терминала.

Поэтому Luma фокусируется на **воспринимаемой точности**, используя математически точные цветовые пространства (Linear RGB vs sRGB) и динамические кривые HDR, а не просто создавая узнаваемый ASCII-арт.
